## 结论

1. **v5 未兑现**：宏 R 0.7559 < 107 的 0.7614（−0.55pp），也略低于 104 的 0.7564（−0.05pp）
2. **patch 池对 bd 的假设成立但幅度不足**：107 的 bd 塌陷（0.318）源于配额被 v4 源图挤占，恢复 patch 池后 +13.7pp，但仍低于 104 的 0.500
3. **过采样 ≠ 正收益**：patch 池里 1245 个 heidian 实例没换来 heidian 提升（0.744 → 0.692），与"背景/额外样本伤 heidian"的历史结论一致
4. **代价是稀释**：583 张 patch（+2866 标注，占总量 44%）把 v4 的 bmss/zy/lj/heidian 增益全部拉回 104 水平 → 类间配额是零和的
5. **唯一亮点**：wy 0.410 为三代池最高（104 0.333 / 107 0.385），弱纹理类对"多实例小图"敏感
6. **当前最优仍是 107**（v4 纹理池，R\@0.25 0.7614）；下一步方向 = 保住 v4 的 bmss/zy 增益，用 *类配额受控* 的方式补 bd（而非整池叠加 patch）
